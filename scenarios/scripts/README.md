# Sample case scripts

The eight transcripts in `../annotations/` are manually authored sample data for product demonstrations and software evaluation. They contain no real patient data or clinical recordings. Each file includes independently specified expected event states and negative controls.

For a live demo, actors may perform these scripts after consenting to local recording. Do not commit the resulting audio. `scripts/generate_demo_audio.sh` can create an uncommitted, clearly synthetic fallback on macOS.
